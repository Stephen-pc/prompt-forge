# 从别人的作品，到你能用的提示词

Prompt Forge 的核心只有一件事：**把「我也想要这种效果」翻译成模型听得懂的话。**

大多数人复现失败，不是模型不行，是描述里塞了一堆模型无法落地的词——「高级感」「氛围感」「电影级」「有质感」。这些词对人是信息，对模型是噪声。真正决定画面的，永远是那七八个具体维度有没有填。

---

## 一、四步逆向法

看到一张图、一段视频、一篇爆款笔记，想做出同款，按这四步走。

### 第 1 步：拆（Decompose）

不要整体描述，先把画面拆成可命名的零件。问自己四个问题：

- 画面里**有什么**？（人/物/景，分别是什么、什么材质、什么状态）
- 它**在干什么**？（动作、姿态、朝向、表情）
- 它**在哪**？（室内外、时间、天气、空间纵深）
- 它是**怎么被拍下来的**？（视角、焦段、光线方向、色调）

拆到你能用名词说清楚每一项为止。「一个很酷的人」不合格，「穿黑色皮夹克的男人，侧身站着，手插口袋，下巴微抬」合格。

### 第 2 步：归（Classify）

把拆出来的零件塞进固定的八个抽屉。这一步的意义是**防止漏项**——漏掉哪一格，模型就在哪一格自由发挥，而它自由发挥的结果通常不是你想要的。

八维骨架见下节。归类的判断标准很简单：一句话只能放进一个抽屉。

### 第 3 步：译（Translate）

日常语言 → 模型认识的术语。这是最容易拉开差距的一步。

| 你想说的 | 写进提示词的 |
|---|---|
| 看起来很贵 | 丝绒质感、黄铜配件、低饱和暖调、柔光箱打光 |
| 很孤独 | 大面积负空间、主体偏右下、冷蓝调、单点光源 |
| 很梦幻 | 柔焦、丁达尔光、粉紫色补光、浅景深 |
| 很复古 | 柯达 Portra 400 胶片颗粒、暖黄偏移、轻微暗角 |
| 很有科技感 | 冷白 LED 边缘光、亚克力反光、青蓝色调、超广角 |
| 手绘感 | 水彩晕染边缘、可见笔触、纸张纹理、留白 |
| 很夏天 | 高曝光、过曝高光、青绿色调、蝉鸣感的暖空气 |

翻译的诀窍：**换成能被拍出来/画出来的物理事实**。写不出物理事实，说明你还没看清。

### 第 4 步：装（Assemble）

按骨架顺序组装，而不是想到哪写到哪。顺序本身携带权重——越靠前，模型越当回事。

## 二、八维骨架（图像/视频通用）

| # | 维度 | 要回答的问题 | 常见错误 |
|---|---|---|---|
| 1 | 主体 | 谁/什么？年龄、种族、发型、服装、材质 | 只写「女孩」，没有可辨识特征 |
| 2 | 动作 | 在做什么？姿态、手势、视线、表情 | 完全省略，模型给个呆站姿势 |
| 3 | 场景 | 在哪？室内外、空间、背景元素、景深 | 背景空泛，画面没有层次 |
| 4 | 风格 | 摄影/插画/3D/油画？参考哪个流派或艺术家 | 「艺术感」——等于没说 |
| 5 | 光线 | 光源方向、软硬、时间、色温 | 最常见的漏项，直接决定画面高级还是廉价 |
| 6 | 色彩 | 主色、辅色、饱和度、色调倾向 | 色彩词互相冲突（又要高饱和又要莫兰迪） |
| 7 | 镜头 | 视角、焦段、构图、景深、画幅 | 省略后构图随机，主体常被切边 |
| 8 | 质感 | 颗粒、噪点、反光、材质细节、渲染器 | 「高清」「8K」堆砌，无实际信息 |

**优先级**：1 → 2 → 5 → 4 → 3 → 7 → 6 → 8。时间紧就填前四个，效果已经能拉开差距。

### 一个对照例子

失败版：

> 一个很酷的赛博朋克女孩，未来感，超高清，8k，杰作

问题：主体无特征、无动作、无场景、无光线、无镜头。所有「质量词」都是空的。

可用版：

> 25 岁亚洲女性，黑色短发被雨水打湿贴在额角，穿磨损的深灰机能风外套，右肩挂一条褪色橙色背带；她侧身站在便利店门口，低头点烟，火苗照亮半张脸；身后是雨夜的窄巷，霓虹招牌在积水里拉出长条倒影；赛博朋克写实摄影；单侧霓虹主光从右后方打来，冷蓝与洋红对冲，环境光极暗；35mm 定焦，略低机位，浅景深，背景虚化成色块；胶片颗粒，轻微暗角，高光有柔光溢出。

同样的模型，差距全在信息密度。

## 三、语序与权重

- **权重递减**：前 20 个词决定 80% 的结果。把最不可妥协的放最前。
- **具体优于抽象**：「木质桌面」优于「有质感的环境」。
- **名词优于形容词**：「柔光箱」优于「柔和的光」。
- **一段式 vs 堆叠式**：
  - 一段自然语言（逗号/分句连写）适合 Midjourney、即梦、可灵这类理解长句的模型。
  - 逗号关键词堆叠适合 Stable Diffusion、Flux 这类 CLIP/T5 编码的模型。
  - 同一份内容，两种写法都备一份，换模型时直接切。
- **权重语法因平台而异**：MJ 用 `::2`，SD 用 `(word:1.3)`，即梦基本不支持权重语法，靠语序和重复。别把 A 平台的语法搬到 B 平台。

## 四、负向提示词

负向不是万能药，但缺了它，手、文字、多余肢体、水印会反复出现。

通用负向（图像）：

> 多余的手指, 畸形的手, 肢体错位, 面部扭曲, 文字, 水印, 签名, 低分辨率, 模糊, 过曝, 噪点, 塑料感皮肤, 重复元素, 画框

按题材追加：

- 人像：`双头, 三只手, 眼睛不对称, 牙齿畸形`
- 建筑：`透视畸变, 歪斜, 结构不合理`
- 产品：`标签错误, 反光过曝, 阴影方向矛盾`

**注意**：部分平台（如即梦、可灵）负向框独立，别写进正向里；Midjourney 用 `--no`。

## 五、迭代策略：一次只改一个变量

复现失败的典型死循环：改十个词 → 结果更差 → 再改十个词 → 完全跑偏。

正确做法：

1. **先锁主体**。只填主体+动作，跑一张，确认人和姿势对了。
2. **再锁场景**。加环境，跑一张，确认空间关系对。
3. **再锁光线**。这是提升质感性价比最高的一步，通常一次就见效。
4. **最后调风格与质感**。锦上添花，改坏了也好回退。

每轮只动一个维度，把有效的版本记下来。三轮之内基本能收敛。

## 六、五个品类的差异

同一套四步法，落到不同品类，维度名不一样。

| 品类 | 骨架维度 | 特有坑 |
|---|---|---|
| 图像 | 主体/动作/场景/风格/光线/色彩/镜头/质感 | 质量词堆砌代替具体描述 |
| 视频 | 主体/动作轨迹/镜头运动/时间节奏/场景/光线/风格 | 只写静态画面，不写「怎么动」，出来是 PPT |
| 文案 | 平台/受众/主题/钩子/结构/语气/禁忌/行动指令 | 只给主题不给平台，语气全错 |
| 网页/代码 | 目标/技术栈/页面结构/交互/视觉规范/边界条件 | 不写约束，模型自由发挥到跑不起来 |
| 音乐 | 流派/情绪/编制/BPM/结构/人声/参考曲目 | 只写「好听的歌」，没有可执行的音乐参数 |

各品类的完整维度清单、术语库和模板，见 `plugin/skills/prompt-forge/references/` 下对应文件，网页版工具里也是同一套。

## 七、一条底线

**提示词是描述，不是许愿。** 每一句都应该是「画面里能被看见的东西」。写完通读一遍，凡是看不见的句子，删掉或改写成看得见的。

这条规则能解决八成的复现失败。
