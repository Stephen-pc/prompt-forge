# 音乐提示词模板库

适用：Suno / Udio / 天工 SkyMusic / 海绵音乐 等 AI 音乐生成。

---

## 一、七维速查

| # | 维度 | 该填什么 | 漏了会怎样 |
|---|---|---|---|
| 1 | 流派 | 具体的子流派，不是大类 | 得到一首四不像 |
| 2 | 情绪 | 具体情绪弧线，不是一个形容词 | 全程一个调，没有起伏 |
| 3 | 编制 | 主奏乐器、节奏组、点缀音色 | 编曲空洞或堆满 |
| 4 | BPM | 具体数字 + 律动感 | 速度不对，情绪就错 |
| 5 | 结构 | 前奏-主歌-副歌-桥段-尾奏 | 平铺直叙，没有记忆点 |
| 6 | 人声 | 性别、音域、唱法、和声 | 声音类型随机 |
| 7 | 参考 | 具体年代、制作风格、混音特征 | 质感廉价 |

**子流派是最大的分水岭。** 写「流行」得到口水歌，写「City Pop / 80s 日本都市流行 / 松原みき 式」得到完全不同的东西。

## 二、术语库

**流派（越具体越好）**
> City Pop / 蒸汽波 / Lo-fi Hip Hop / 后摇 / 数学摇滚 / 盯鞋 / Dream Pop / 氛围电子 / Future Bass / Deep House / 民谣流行 / 卧室流行 / 巴洛克流行 / 爵士嘻哈 / Bossa Nova / 中国风五声音阶 / 古风流行 / 电子民乐 / 电影配乐 / 极简主义

**情绪**
> 克制的怀念 / 潮湿的夏天傍晚 / 深夜独处的松弛 / 即将告别的平静 / 压抑后释放 / 悬疑不安 / 明亮轻盈 / 苦涩自嘲

注意：**不要写「悲伤」这种单点词，写情绪弧线**——「从压抑到释然」。

**编制**
> 电钢琴 + 指弹吉他 + 轻鼓刷 / 808 低音 + 空灵合成器 pad / 弦乐四重奏 + 钢琴 / 木吉他 + 手鼓 + 口琴 / 合成器 arpeggio + 侧链压缩 pad

**混音质感**
> 磁带饱和 / 黑胶底噪 / 80 年代门限混响 / 大空间板式混响 / 干燥近场 / 宽立体声合成器 / 人声前置、乐器退后

## 三、模板

### 3.1 完整歌曲（带歌词）

```
【风格】{具体子流派}，融合 {次要元素}
【情绪】{情绪弧线：从 A 到 B}
【BPM】{数值}，{律动描述：如 半拍摇摆 / 四踩 / 切分}
【编制】{主奏} + {节奏组} + {点缀音色}
【人声】{性别}，{音域}，{唱法：气声/真声/假声转换}，副歌加 {和声}
【结构】
  Intro（{乐器}独奏，{秒数}秒）
  Verse 1（低音区，克制）
  Pre-Chorus（加入 {乐器}，情绪抬升）
  Chorus（全编制，人声最高点）
  Verse 2（加 {新元素} 保持新鲜）
  Bridge（{变化：转调/减编制/节奏突变}）
  Final Chorus（加 {和声/弦乐} 加厚）
  Outro（{乐器}淡出）
【混音】{质感描述}
【歌词】
  主题：{主题}，视角：{第一人称/第二人称}，意象：{2–3 个具体意象}
  副歌要有可跟唱的一句，不超过 12 字
  避免直白说「我爱你」「我难过」，用具象场景替代
```

### 3.2 纯音乐 / BGM

```
【用途】{视频配乐/游戏场景/播客背景}
【风格】{子流派}
【情绪】{弧线}
【BPM】{数值}
【编制】{乐器}
【结构】不要人声；{时长}秒；前 8 秒建立氛围，中段有 1 次动态起伏，结尾自然收束不留悬念
【混音】{质感}，中频留出人声空间
```

### 3.3 短片段 / 15 秒

```
【风格】{子流派}
【情绪】{单一情绪，不要弧线}
【BPM】{数值}
【记忆点】开头 2 秒必须有 {辨识度元素：如 标志性和弦/采样/鼓点}
【结构】直接进副歌，15 秒，结尾不淡出，硬切
```

## 四、歌词写作要点

1. **副歌一句话可跟唱**。超过 12 字没人记得住。
2. **用具象替代抽象**。不写「我很想你」，写「你的杯子还在窗台上，我一直没洗」。
3. **主歌铺场景，副歌给结论**。反过来会很空。
4. **押韵不必严格**。现代流行歌更看重口语节奏，强行押韵反而生硬。
5. **留白**。一段歌词里塞满信息，唱起来没有呼吸口。

---

## 五、避坑清单

1. **写大类不写子流派** = 最平庸的那首。
2. **情绪写成一个词** = 全程一个调，没有起伏。
3. **不给 BPM** = 速度随机，情绪对不上。
4. **不给结构** = 平铺直叙，听完记不住。
5. **歌词写太满** = 唱不下，或者被压缩得含糊。
6. **平台差异**：Suno 支持段落标签（`[Verse]` `[Chorus]` `[Bridge]`），Udio 对风格描述更敏感但结构控制弱。用段落标签能显著提升结构准确度。
