# 文案提示词模板库

适用：小红书 / 公众号 / 抖音口播 / 广告语 / 电商详情页 / 长文。

---

## 一、八维速查

| # | 维度 | 该填什么 | 为什么关键 |
|---|---|---|---|
| 1 | 平台 | 小红书/公众号/抖音/知乎/详情页 | 决定篇幅、语气、排版、能不能用 emoji |
| 2 | 受众 | 年龄、身份、痛点、当前认知 | 决定说什么、怎么说 |
| 3 | 主题 | 一句话说清要讲什么、观点是什么 | 不给观点，模型只能写正确的废话 |
| 4 | 钩子 | 开头三秒抓人的那一句 | 决定 80% 的完读率 |
| 5 | 结构 | 总分总 / 痛点-方案-证据 / 清单体 / 故事体 | 决定读起来累不累 |
| 6 | 语气 | 闺蜜聊天 / 专业顾问 / 犀利吐槽 / 温柔治愈 | 决定像不像人写的 |
| 7 | 禁忌 | 不能提的竞品、不能用的绝对化词、合规红线 | 决定能不能发 |
| 8 | 行动指令 | 想让读者看完做什么 | 决定有没有转化 |

**最常见的漏项是第 1 和第 6**。只给主题不给平台，模型会默认写成公众号散文——发到小红书就是灾难。

---

## 二、平台语气对照

| 平台 | 篇幅 | 语气 | 排版特征 |
|---|---|---|---|
| 小红书 | 300–600 字 | 第一人称、闺蜜感、有情绪起伏 | 短句分段、emoji 分隔、结尾话题标签 |
| 公众号 | 1500–3000 字 | 有观点、有论证、克制 | 小标题分节、长段落、少 emoji |
| 抖音口播 | 150–250 字（60–90 秒） | 口语、有节奏、有停顿点 | 短句、设问、口语连接词 |
| 知乎 | 800–2000 字 | 理性、给依据、承认局限 | 分点、数据、引用 |
| 电商详情页 | 分段模块 | 卖点前置、利益点明确 | 小标题 + 参数 + 场景化描述 |

## 三、钩子写法（开头第一句）

| 类型 | 模板 | 例子 |
|---|---|---|
| 反常识 | 大家都以为 X，其实 Y | 大家都以为早睡靠自律，其实是靠把手机放到另一个房间 |
| 身份代入 | 如果你是 X，这条一定要看 | 如果你是刚工作的应届生，这条能帮你省三千块 |
| 结果前置 | 我用 X 做到了 Y | 我用一个破 Excel 表，把加班时间砍掉一半 |
| 痛点直击 | 你是不是也…… | 你是不是也收藏了几百条笔记，一条都没用过 |
| 悬念缺口 | 直到我发现了一件事 | 我用了三年才发现，问题根本不在工具上 |
| 数字具体 | 3 个 / 7 天 / 90% | 7 天，我把房间从仓库改成了能待人的地方 |

## 四、模板

### 4.1 小红书笔记

```
【角色设定】你是{领域}博主，写一篇{主题}的小红书笔记。
【受众】{年龄/身份/痛点}
【钩子】开头用{钩子类型}，第一句不超过 20 字。
【结构】
  1. 痛点共鸣（2–3 句，说中具体场景）
  2. 我的做法（3–4 条，每条一句结论 + 一句解释）
  3. 效果（具体数字或前后对比）
  4. 收尾（一句轻观点，不喊口号）
【语气】第一人称，像跟朋友聊天，可以有犹豫和自我怀疑，不要完美人设。
【排版】每段 1–2 句，段间空行，适度 emoji（不超过 8 个），结尾 3–5 个话题标签。
【禁忌】不用「最」「第一」「绝对」等绝对化表述；不虚构医疗/金融效果。
【字数】400 字左右。
```

### 4.2 公众号长文

```
【角色】你是{领域}的长期写作者，观点克制，不煽动。
【主题】{主题}，核心观点是：{一句话观点}
【受众】{画像}，他们已经知道{基础认知}，不需要科普。
【结构】
  1. 一个具体场景或事件切入（不要宏大开场）
  2. 提出反常现象
  3. 给出解释（2–3 层，层层递进）
  4. 承认反例与局限
  5. 落到可执行的一两条建议
【语气】冷静、有判断、允许不确定。避免感叹号和排比句。
【禁忌】不用「赋能」「抓手」「闭环」等黑话；不写空洞总结段。
【字数】2000 字左右。
```

### 4.3 短视频口播脚本

```
【主题】{主题}，目标时长 {60}秒
【受众】{画像}
【结构】
  0–3 秒：钩子（{钩子类型}），必须让人停下滑动
  3–15 秒：说清问题，用具体场景不用概念
  15–50 秒：给方法，2–3 个点，每点一句结论 + 一个例子
  50–60 秒：一句总结 + 一个引导动作
【语气】口语，短句，允许口头语（「说白了」「你想想」），不要书面语。
【标注】在需要强调的词后面标【重音】，在需要停顿处标【停顿】。
【禁忌】不念稿感；不用「大家好我是XX」开场。
```

### 4.4 广告语 / 标语

```
【产品】{产品}，核心卖点是{卖点}
【受众】{画像}
【要求】生成 10 条，每条不超过 12 字，口语化，有记忆点。
【风格分组】3 条利益直给 / 3 条情绪共鸣 / 2 条反差幽默 / 2 条场景代入
【禁忌】不用谐音梗凑数；不用「极致」「尊享」等空词。
```

## 五、让文案「不像 AI 写的」的五条

1. **删掉总结段**。AI 最爱在结尾写「总而言之，让我们一起……」，人不会这么说话。
2. **加具体细节**。不写「提升效率」，写「原来两小时的活，现在二十分钟」。
3. **允许不确定**。「我也不太确定这样对不对，但目前看是有效的」比「这个方法绝对有效」可信十倍。
4. **句子长短交错**。全是一个长度的句子，读起来就是机器。插一个四字短句。
5. **去掉排比和并列三连**。「不仅是……更是……还是……」是 AI 指纹。

---

## 六、避坑清单

1. 不给平台 = 语气全错，这是第一杀手。
2. 不给受众 = 说给所有人听 = 没人听。
3. 要求「爆款」= 模型只能堆情绪词，反而更假。
4. 一次要 20 条 = 全是平均水平的废话。要 5 条，分两轮。
5. 广告法红线：绝对化用语、虚假功效、贬低竞品，模型不会主动避，必须写进禁忌。
