## 三、模板

### 3.1 通用写实（自然语言一段式，适合 MJ / 即梦）

```
{年龄性别种族}{发型}{服装与材质}，{动作姿态与表情}，在{场景与背景元素}；
{风格}；{光线方向与色温}，{色彩倾向}；{焦段}{机位}{构图}{景深}；{质感与后期}
```

### 3.2 关键词堆叠（适合 SD / Flux）

```
{subject}, {hair}, {outfit}, {pose}, {expression}, {location}, {background detail}, {style}, {lighting}, {color palette}, {lens}mm, {angle}, {composition}, {depth of field}, {texture}, {renderer}, masterpiece, best quality
```

Negative：
```
extra fingers, deformed hands, malformed limbs, distorted face, text, watermark, signature, lowres, blurry, overexposed, plastic skin, duplicate
```

### 3.3 产品图

```
{产品}置于{台面材质}上，{摆放角度}，{配件/道具}，背景为{纯色/渐变/场景}；
商业产品摄影，{光线}，{反光控制}；{焦段}，{俯拍/平视}，{留白比例}；{质感}
```

要点：产品图最忌「反光过曝」和「阴影方向矛盾」，负向里一定加。

### 3.4 人物海报

```
{人物特征}，{姿态}，{服装}，居中构图，{背景元素与留白}；
{风格}；{轮廓光/边缘光}，{主色调}；{焦段}，{机位}；{质感}
顶部与底部留出文字安全区
```

### 3.5 场景/建筑

```
{建筑类型与材质}，{时间与天气}，{前景/中景/远景层次}；
{风格}；{自然光方向}，{人工光源}；{焦段}，{一点透视/两点透视}，{对称构图}；
{质感}，透视准确，结构合理
```

## 四、平台差异

| 平台 | 语法特点 | 建议 |
|---|---|---|
| Midjourney | 长句理解好；`--ar` `--style` `--no` 参数 | 一段式自然语言 + 参数尾巴 |
| Stable Diffusion | CLIP 编码，关键词堆叠；支持 `(word:1.3)` | 逗号堆叠，权重控制在 1.3 以内 |
| Flux | T5 编码，长句理解强 | 完整句子，少用权重语法 |
| 即梦 / 可灵 | 中文长句，负向独立输入框 | 中文描述，负向单独填 |
| DALL·E | 语义理解强，细节会自行补全 | 描述意图而非堆词，避免风格冲突 |

## 五、避坑清单

1. **不要堆质量词**。`8K, ultra detailed, masterpiece` 对多数模型已无实际增益，反而挤占语义空间。
2. **不要自相矛盾**。`高饱和 + 莫兰迪`、`柔光 + 硬阴影`、`极简 + 繁复装饰` 会让模型二选一或折中成四不像。
3. **不要漏光线**。这是质感差距的最大来源。
4. **不要漏镜头**。构图随机是「不像参考图」的头号原因。
5. **一次只改一个维度**。同时改五个词，你不知道哪个起了作用。
6. **人像必加负向**。手、眼、牙齿是崩坏高发区。
7. **文字别指望模型写对**。需要文字就后期加，或在提示词里明确 `no text` 留白。
