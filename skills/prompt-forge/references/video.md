# 视频提示词模板库

适用：可灵 / 即梦 / 海螺 / Runway / Pika / Sora / Veo 等文生视频、图生视频。

---

## 一、核心差异：视频要写「怎么动」

图像提示词描述**一帧**，视频提示词描述**一段变化**。只写静态画面，出来就是「一张图轻微晃动」——这是复现视频最常见的失败。

视频骨架在八维基础上，必须额外回答三个问题：

1. **动作轨迹**：主体从哪到哪，速度如何，有没有加速度
2. **镜头运动**：机器怎么动（推/拉/摇/移/跟/升降/环绕）
3. **时间节奏**：这段几秒，慢动作还是快切，有没有转折点

---

## 二、十维速查

| # | 维度 | 该填什么 |
|---|---|---|
| 1 | 主体 | 外观特征（同图像） |
| 2 | 动作 | 具体动作 + 起始状态 + 结束状态 |
| 3 | 镜头运动 | 推/拉/摇/移/跟/升降/环绕/手持/固定 |
| 4 | 节奏 | 慢动作 / 正常 / 延时 / 加速 / 停顿 |
| 5 | 场景 | 空间与背景（同图像） |
| 6 | 光线 | 光源与变化（如「光线由暗转亮」） |
| 7 | 风格 | 实拍/动画/3D/胶片 |
| 8 | 色彩 | 色调与变化 |
| 9 | 景别 | 远景/全景/中景/近景/特写 |
| 10 | 时长与画幅 | 3s/5s/10s，16:9 / 9:16 / 1:1 |

## 三、镜头运动术语

> 推镜（dolly in）/ 拉镜（dolly out）/ 摇镜（pan）/ 俯仰（tilt）/ 横移（truck）/ 跟拍（tracking）/ 升降（crane）/ 环绕（orbit）/ 手持晃动（handheld）/ 斯坦尼康（steadicam）/ 固定机位（static）/ 变焦推拉（dolly zoom）/ 第一人称（POV）/ 航拍俯冲（drone dive）

## 四、模板

### 4.1 通用叙事（5 秒）

```
【主体】{外观特征}，【起始】{初始动作/姿态}，【过程】{动作如何发展}，【结束】{最终状态}；
【镜头】{镜头运动}，从{景别A}到{景别B}；
【场景】{环境}，【光线】{光源与变化}，【风格】{风格}，【节奏】{速度}，【画幅】{比例}
```

### 4.2 图生视频（首帧固定）

```
以首帧为基础，保持人物外观、服装与背景一致；
【动作】{主体做什么，幅度多大}；
【镜头】{轻微推近 / 缓慢横移 / 固定}；
【氛围】{光线变化、环境动态如雨丝、烟雾、飘落物}
```

图生视频要点：**动作幅度写小一点**。模型对大幅度动作容易崩坏面部和手部，写「轻轻转头」「发丝被风吹动」比「转身奔跑」成功率高得多。

### 4.3 产品演示

```
{产品}置于{环境}，{起始角度}；
【镜头】缓慢环绕 90 度，保持产品居中；
【光线】{主光}从{方向}扫过，高光沿{材质}表面移动；
【节奏】匀速，无抖动，商业广告质感
```

### 4.4 空镜/氛围

```
【场景】{环境描述}，【动态元素】{雨/雪/烟/云/水波/光斑}；
【镜头】{固定机位 / 极缓慢横移}；
【光线】{时间与色温}，【风格】{电影感/胶片}，【节奏】慢
```

## 五、避坑清单

1. **写「变化」不写「状态」**。「一个女孩站在雨里」→「雨滴落在她肩上，她缓缓抬头」。
2. **动作幅度别贪大**。多主体交互、快速转身、手部精细动作是崩坏高发区。
3. **镜头运动只写一种**。「一边推进一边环绕同时上升」模型做不到，会糊。
4. **明确时长**。多数平台默认 3–5 秒，超出会截断或重复。
5. **首尾帧一致性**。需要循环或衔接时，明确「结束状态与起始状态一致」。
6. **别在视频里要求文字**。字幕、logo 一律后期加。
7. **负向同样重要**：`画面抖动, 变形, 肢体扭曲, 面部崩坏, 闪烁, 重复帧, 文字, 水印`。
